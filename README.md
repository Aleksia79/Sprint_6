# Sprint_6
- Проект автоматизации тестирования онлайн-сервиса заказа самокатов "Яндекс.Самокат"

## Требования
- Для запуска тестов должны быть установлены пакеты pytest и selenium
- для получения отчета должен быть установлен пакет allure_pytest 
- Запуск всех тестов выполняется командой pytest -v
- driver - фикстура для создания драйвера Firefox в conftest.py
- локаторы в папке locators
- URL главной страницы "Яндекс.Самокат" и главной страницы "Дзен" в config.py 
- тестовые данные для оформления заказов и выпадающих списков в разделе "Вопросы о важном" в data.py
- allure-отчет - в папке allure_results
- allure-отчет в формате веб-страницы формируется командой allure serve allure_results
